# 数据模型：检索链路优化（012）

## 检索变体（RetrievalVariant）

- **query_text**：原句（含既有事实/编号拼接改写后的文本）；始终参与多路，不可被变体替换。
- **variants**：0-3 条变体文本；与原句空白归一化后相同者剔除；语义不得偏离原句。
- **状态**：生成成功（0-3 条，0 条等价单路）/ 生成失败（回退单路）。无持久状态，单次检索内即弃。

约束：变体生成失败不产生错误输出（FR-004）；变体只影响召回与排序，不进入回答正文。

## 检索存档（RetrievalArchive）

- **question_id / question_type**：题库标识与主类；只来自评测材料。
- **dialect / path**：查询口径（initial/full/actual/variants…）× 检索路径（vector/hybrid/variants/id…）。
- **query / variants**：实际检索文本与变体列表。
- **ranked**：前 N（默认 20）片段，保序；每项含 `passage_id`、`doc_id`、`chunk_no`、`score`、`text`（rerank 需正文）。
- **版本**：生成时间、知识集合 id、检索配置标注。

约束：JSONL 行式；可部分重跑；评测标注不进产品运行时（spec 边界场景）。

## 达标判定（AcceptanceVerdict）

- **subject**：判定对象（变体口径 / ID 口径 / 精排对照）。
- **metric**：recall@10 差值（pp）、逐题型差值、单轮不降校验；精排另含单次延迟 P50。
- **threshold**：变体 +10pp；ID +10pp；精排 +5pp 且 P50 ≤500ms。
- **result**：达标 / 未达标；未达标必须附带触发条件（下一条实体）。

## 触发条件（TriggerCondition）

- **subject**：被搁置的改造（逐 ID 关键词路 / 精排组件）。
- **signal**：可检验的复测信号（例如：新口径检索诊断显示含编号查询召回不足 / 变体口径剩余排序空间 ≥5pp）。
- **method**：复测口径与判定线（不得使用已被推翻的口径，如整句 ILIKE 对照）。

约束：触发条件不得失义——引用时按其记录的口径与方法执行；无触发条件的"未达标"视为死条款（SC-003）。

## 关系

- 检索变体 →（多路融合产生）检索结果排名 →（评测采样）检索存档。
- 检索存档 →（对照实验）达标判定 →（未达标时）触发条件。
- 达标判定 →（达标时）产品实施（对应 FR 条款）。
